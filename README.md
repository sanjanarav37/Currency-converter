# 💱 Currency Converter

A simple and responsive currency converter built using HTML, CSS, and JavaScript. It uses an API to fetch exchange rates and convert currencies in real time.

## 🌐 Live Demo

[**View Live Demo →**](YOUR-LIVE-DEMO-LINK)

## ✨ Features

- 🌍 Convert between multiple currencies
- 💱 Real-time exchange rates using API
- 🚩 Currency flags
- 🔄 Currency selection
- ✅ Input validation
- 📱 Responsive design
- ✨ Interactive hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API

## 🚀 How to Use

1. Enter the amount you want to convert.
2. Select the currency you want to convert **from**.
3. Select the currency you want to convert **to**.
4. Click **Get Exchange Rate**.
5. The converted amount will be displayed.
